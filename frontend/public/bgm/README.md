# 环境音床

前端按 `/bgm/{标识}.mp3` 加载。标识来自模组的 `sceneBgm` 映射（场景ID → 标识），
后端通过 `getState().bgm` 下发。

**文件缺失不是错误**：没有对应文件时前端静默不放，不影响任何叙事流程。可以只放一两条先试。

## 十条床

覆盖当前全部三个模组。少量床复用多个场景，而不是一场景一曲——环境音标记的是**空间性质**，
不是房间编号。房间级切换既做不起，听感上也会露出拼接痕迹。

| 文件 | 空间性质 | 用在哪 |
|---|---|---|
| `town.mp3` | 白天小镇，人声与街市底噪 | 普瑞米尔、旅店 |
| `domestic.mp3` | 有人居住的私人空间，安静但不空旷 | 特里坎家、加比的拖车房 |
| `tavern.mp3` | 室内嘈杂，人声混响 | 维森酒吧 |
| `institutional.mp3` | 机构建筑，空调与日光灯低频嗡鸣 | 霍姆斯医院、警察局、证物室、与艾德里安的会面 |
| `derelict.mp3` | 废弃荒芜，风声与结构受力声 | 交火现场、艾德里安的住宅／农场／卧室、农场主别墅 |
| `dread.mp3` | 恐怖核心，机械低频与不安定感 | 谷仓形建筑、建筑内、中控室、维修间、奇怪管道、棺材 |
| `underground.mp3` | 地下封闭，水滴与狭窄混响，无风 | 下水道、图书馆地下室 |
| `coast.mp3` | 海岸，浪涌、木结构吱响、海鸟 | 印斯茅斯码头、礁石 |
| `sacred.mp3` | 仪式空间，石质长混响，远处人声 | 大衮教堂 |
| `library.mp3` | 学术空间，极安静，纸张与木地板 | 密斯卡托尼克图书馆、珍本库 |

未来模组如需新床，建议沿用「空间性质」而非「地点名」来命名，例如
`forest` / `train` / `hospital_night` / `storm`。命名指向性质，复用率才高。

## 制作约束

- **循环无缝**，长度 60–120 秒以上。太短会听出重复，这是最容易露馅的地方。
- **无旋律。** 这是环境音床不是配乐。有旋律会和叙述抢注意力，也是版权风险的主要来源。
- 前端播放音量固定 `0.35`，按"垫在人声之下"的标准混音，不要做成前景音乐。
- 默认静音，需玩家点开——浏览器会拒绝未经交互的自动播放。
- 避免可辨识的乐器演奏动机。低频、噪声层、环境实录是安全区。

## 制作配方（CC0 素材叠加）

恐怖底噪的本质是噪声塑形，不是作曲。以下配方全部可用 CC0 实地录音加常规处理链完成，
不需要作曲能力，也不涉及任何版权模糊地带。

通用处理链：**低通滤波（去掉刺耳高频）→ 长混响 → 极慢音量起伏（LFO 0.05–0.1Hz）→ 限幅**。
最后那步音量起伏是关键，它让静态噪声听起来像"活的空间"。

| 床 | 素材层 | 处理要点 |
|---|---|---|
| `town` | 远处人声嘈杂 + 偶发马车／汽车 + 风 | 人声压到听不清词的程度，只留韵律 |
| `domestic` | 室内房间底噪 + 挂钟 + 偶发木结构声 | 极安静，靠偶发声件撑住"有人住"的感觉 |
| `tavern` | 人群交谈 + 杯盘 + 木地板 | 混响短、密度高，与 `town` 的区别在于封闭感 |
| `institutional` | 空调低频 + 日光灯 50/60Hz 嗡鸣 + 远处脚步 | 电器嗡鸣是灵魂，频率保持恒定不要飘 |
| `derelict` | 风穿过缝隙 + 木／金属结构受力 + 远处鸟 | 声件之间留长间隙，空旷感来自留白 |
| `dread` | 机械低频 + 风扇 + 极低频次声（20–40Hz） | 次声层是生理性不安的来源，音量要低到"感觉得到但听不见" |
| `underground` | 水滴 + 狭窄空间混响 + 低频轰鸣 | 混响短促且金属化，与 `dread` 的开阔低频区分开 |
| `coast` | 浪涌 + 木栈桥吱响 + 海鸟 + 风 | 浪的周期不要太规律，否则会显得像循环 |
| `sacred` | 石质长混响 + 极远处人声吟唱 + 烛火 | 吟唱压到几乎听不出是人声，只留混响尾巴 |
| `library` | 纸张 + 木地板 + 极远处钟摆 | 这条最难：安静到几乎无声，但不能是纯静音 |

素材来源建议 Freesound 筛 CC0（注意区分 CC0 与 CC-BY），或自行实地录制。

## 版权

**不要使用任何商业游戏的原声。** 涉及词曲著作权与录音制作者权两重权利，
「非商业」在中国《著作权法》下不构成抗辩（合理使用是封闭列举，"个人欣赏"不覆盖通过网络向他人提供）。

按上面的配方做出来的东西不存在侵权问题：环境噪声没有旋律，通用表达不受版权保护，
两条独立制作的"工业低频底噪"听起来像是因为物理相似，不是因为抄袭。

若改用 AI 生成，注意两点：提示词**不要点名任何作品或作曲家**（既会推高相似度，也留下主观意图的证据）；
各服务的商用条款差异很大，且训练数据的合法性仍在诉讼中（RIAA 于 2024 年起诉 Suno 与 Udio），需自行确认。
CC-BY 素材必须署名，漏署名同样构成侵权。
