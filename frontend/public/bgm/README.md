# 环境音床

前端按 `/bgm/{标识}.mp3` 加载。标识来自模组的 `sceneBgm` 映射（场景ID → 标识），
后端通过 `getState().bgm` 下发。

**文件缺失不是错误**：没有对应文件时前端静默不放，不影响任何叙事流程。可以只放一两条先试。

## 《普瑞米尔的谷仓》用到的六条

| 文件 | 覆盖场景 | 性质 |
|---|---|---|
| `town.mp3` | 普瑞米尔、旅店 | 白天小镇，人声与街市底噪 |
| `domestic.mp3` | 特里坎家、加比的拖车房 | 有人居住的私人空间，安静但不空旷 |
| `tavern.mp3` | 维森酒吧 | 室内嘈杂，人声混响 |
| `institutional.mp3` | 霍姆斯医院、警察局、证物室、与艾德里安的会面 | 机构建筑，空调与日光灯的低频嗡鸣 |
| `derelict.mp3` | 交火现场、艾德里安的住宅／农场／卧室、农场主别墅 | 废弃与荒芜，风声与结构受力声 |
| `dread.mp3` | 谷仓形建筑、建筑内、中控室、下水道、维修间、奇怪管道、棺材 | 恐怖核心区，机械低频与不安定感 |

六条床复用 21 个场景，而不是一场景一曲——环境音标记的是**空间性质**，不是房间编号。
房间级切换既做不起（22 首），听感上也会露出拼接痕迹。

## 制作约束

- **循环无缝**，长度建议 60–120 秒以上，太短会听出重复。
- **无旋律**。这是环境音床不是配乐，有旋律会和叙述抢注意力，也更容易撞版权。
- 前端播放音量固定 `0.35`，混音时按"垫在人声之下"的标准做，不要做成前景音乐。
- 默认静音，需玩家点开——浏览器会拒绝未经交互的自动播放。
