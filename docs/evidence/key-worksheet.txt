# 条目评分键 · 工作表

每个 ▶ 条目配上它所在场景的基准对象。逐条填「实际是」那一栏。

可选值：`clue:<id>` / `item:<id>` / `connection` / `npc_knowledge` / `npc_secret`
        / `event`（分支叙事，基准里没有对应结构） / `none`（基准根本没收）
        / 双角色写两个，逗号分隔

判断依据只看基准怎么收的，不看分类器说什么——那一栏并排放着是为了事后算准确率，
不是为了参考。
